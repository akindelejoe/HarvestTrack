#  Crop Harvest Tracker

A simple Node.js CLI application that helps users track crop planting and harvest timelines.  
The app stores data in MongoDB Atlas using Mongoose for persistence.

---

##  Features
- Add crops with type, location, and planting date.  
- View all crops with days left until harvest.  
- Delete crops by type.  
- Automatic harvest date calculation.  
- Alert when harvest is less than a week away.
